# TVC-3D-sim-game
## what is it and my motivation?
this is a 3D TVC rocket simulation with VTVL (not polished really) capabillities like a SPACEx rocket. I built this to mirror my model VTVL electric( so sustainable) with easier physics ulike real physics which will absolutely make the sim infinitely harder(will soon add that too!). It is a basic MVP which i had to debugg a lot because of this raylib.

## How to Run?
First in your terminal make sure you have raylib installed

``` bash
pip install raylib
```
also pyinstaller
```bash
pip install pyinstaller
```
How to play?

well its:
-W, S for movement;
-A, D for tvc controlls( only one axis now unfortunately);
-L for landing legs;
-Space for landing burn;
-Enter for launch;
